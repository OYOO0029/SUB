# 업무 화면 디자인 및 편집 규칙

## 프로젝트 리스트 — 현재 구현

- 목록은 프로젝트 / 진행 상태 / 남은 할 일 / 다음 마감 / 열기 표입니다. 미완료 실제 마감의 최솟값을 표시하며 날짜 없는 항목은 정렬 방향과 무관하게 마지막에 둡니다.
- 이름 헤더에서 검색·정렬, 상태 헤더에서 복수 선택 필터, 마감 헤더에서 필터·정렬을 제공합니다. 상단은 결과 수·정렬·추가만 표시합니다.
- 상세는 프로젝트명·상태·더보기, 완료 수·상태 필터·추가 도구, 업무 묶음별 표로 구성합니다. 일반 할 일이 없으면 일반 구역을 생략하고 사용자 생성 빈 업무 묶음은 제목·추가·정보 진입점만 유지합니다.
- 추가 입력창은 해당 구역 ＋로 열고 Enter 또는 ＋로 저장, Esc 또는 닫기 아이콘으로 취소합니다. 한글 조합 중 Enter는 저장하지 않습니다.
- 완료는 미완료 보기 하단에서 접어 보거나 완료 필터로 조회합니다. 취소는 별도 필터로 조회하며 완료 수에 합산하지 않습니다.
- 상세·집중 패널은 프로젝트 화면을 유지한 채 공통 패널을 사용합니다. 미니 타이머에서도 현재 탭 안에 패널을 열며 탭을 강제로 이동하지 않습니다.

## 리스트 정렬 — 최신 설계 기준

프로젝트 개편은 리스트로 진행하며 아래 과거 카드 구성보다 우선합니다. 공통 적용 범위와 검수는 WORKING_RULES.md의 ‘리스트 UX 규칙 — 최신 기준’을 따릅니다.

| 영역 | 항목 | 가로 정렬 |
|---|---|---|
| 헤더 | 모든 열 제목 및 제목과 함께 표시하는 정렬·필터·드롭다운 아이콘 묶음 | 가운데 |
| 본문 | 프로젝트명·업무명·할 일 제목·설명 등 긴 텍스트 | 왼쪽 |
| 본문 | 마감일·날짜·시간·진행 상태·개수·완료 비율 | 가운데 |
| 본문 | 체크박스·이동 화살표·집중·더보기·동작 버튼 | 가운데 |

- 셀 내부는 모두 세로 가운데 정렬합니다. 헤더의 아이콘은 제목과 4px 간격, 공통 12px 화살표 기준을 유지하며 표시 상태가 바뀌어도 묶음 위치가 흔들리지 않게 합니다.
- 긴 텍스트의 정렬을 맞추기 위해 헤더까지 왼쪽 정렬하지 않습니다. 긴 이름은 자기 열 안에서 처리하고 날짜·상태·아이콘 열의 폭과 중앙 기준선을 유지합니다.

## 오늘 목록 배치 — 최신 기준

- 리스트·타임라인은 이름 툴팁이 있는 아이콘 전환입니다. 왼쪽에 보기, 오른쪽에 상태와 정렬·추가를 한 줄로 표시합니다. 580px 이하에서는 상태 필터만 다음 줄에 둡니다.
- 기존 마감 지난 일과 다가오는 일·이전에 못 끝낸 일의 데이터 범위를 합쳐 ‘남은 할 일’ 영역으로 표시합니다. 범위를 넓히거나 일정을 변경하지 않습니다.
- 남은 할 일은 접지 않고 구분선·24px 여백 아래 항상 펼쳐 표시합니다. 항목이 없으면 빈 구역을 생략합니다. 완료 체크 → 프로젝트 → 할 일 → 마감 → 오늘 하기 테이블을 사용하며 오늘 목록과 열 기준선을 공유합니다. 마지막 열은 두 표 모두 80px입니다.
- ‘오늘 하기’는 기존 계획 추가·실행 취소 동작을 사용합니다. 제목은 공통 상세 패널을 열고 체크박스는 완료 상태만 변경합니다. 타임라인의 보조 목록에도 같은 남은 할 일 구역을 사용합니다.

## 공통 UX — 2026-10-27 최신 기준

이 절은 아래의 화면별 과거 치수·타이머 레이아웃보다 우선합니다. 오늘 할 일·프로젝트·캘린더에 `common-ux.css`의 공통 토큰을 적용합니다.

- 탐색과 캘린더 보기 전환은 텍스트, 오늘 할 일의 보기 전환은 아이콘, 도구와 집중 조작은 아이콘만 사용합니다. 선택 메뉴는 텍스트와 12px SVG 화살표를 사용합니다. 정렬은 모든 화면에서 같은 sort 아이콘, 필터는 filter 아이콘입니다.
- 기본 컨트롤 32px, 아이콘 16px, 간격 8px, 모서리 6px. 보기 탭 간격 4px, 텍스트와 화살표 간격 4px. 터치 환경은 조작 높이 44px입니다.
- 탭·버튼·프로젝트명 13px/400, 할 일 제목 14px/400, 보조 정보 12px/400, 상세 제목 16px/600. 선택된 탭은 600입니다.
- 콘텐츠 상단 16px, 도구에서 내용까지 12px. 세 화면의 좌우 기준선을 통일합니다. 캘린더의 날짜는 좁은 화면에서 별도 행으로 배치하며 날짜 셀·이벤트의 밀도는 보존합니다.
- 리스트·타임라인 전환은 같은 위치의 아이콘 버튼이며 기능명 툴팁과 선택 상태를 제공합니다. 타임라인에 고정 원형 타이머를 두지 않습니다. 일정 제목은 상세, 집중 아이콘은 타이머 패널, 시간은 배치 편집을 엽니다.
- 타이머는 집중 아이콘을 눌렀을 때만 패널을 열며 자동 시작하지 않습니다. 실행 후 닫으면 하단 미니 바를 유지합니다. 프로젝트·캘린더에서도 미니 바를 유지하고, 클릭하면 현재 탭에서 공통 집중 패널을 엽니다. 패널과 미니 바를 중복 표시하지 않습니다.
- 빠른 시간 선택은 10/20/30/60분이며 직접 입력을 유지합니다. 보기 전환·패널 닫기로 타이머를 초기화하지 않고, 종료가 할 일을 자동 완료하지 않습니다.
- 테스트: 화면 전환 시 타이머 상태, 패널 중복, 실제 마감·배치·계정 데이터 보존과 각 탭의 작은 화면 정렬을 확인합니다.

## 간격·정렬 보정 — 최신 기준

- 콘텐츠의 중복 ‘오늘 할 일’ 제목과 날짜는 표시하지 않습니다. 상단 탐색 탭으로 위치를 구분합니다.
- 오늘 할 일 / 프로젝트 / 캘린더 탭은 32px 높이, 13px 글자, 좌우 10px, 탭 사이 4px입니다. 탐색 영역 상하 여백은 12px입니다.
- 오늘 콘텐츠 상단 16px, 도구와 목록 사이 12px. 도구와 목록 좌우 기준선은 같습니다.
- 도구 아이콘은 16px, 버튼은 32×32px, 가로·세로 중앙에 배치합니다. 표의 집중 버튼도 32×32px이며 열 가운데에 놓습니다.
- 목록 행은 48px, 헤더는 40px. 기본 셀 좌우 10px, 체크 열은 44px·가운데, 집중 열은 48px·좌우 8px입니다.
- 목록에 최소 높이를 강제해 빈 공간을 만들지 않습니다. 320/390px에서는 표 내부만 가로 스크롤하며 페이지 전체에는 가로 넘침이 없어야 합니다.
- `tests/today-layout-preview.html`은 로컬 가상 계정에서 1280/1024/720/390/320px의 실제 렌더링 치수와 아이콘 중앙 오차를 확인합니다.

## 오늘 할 일 테이블 — 현재 요청 기준 (기존 목록 규칙보다 우선)

- 변경 대상은 오늘 할 일 목록 영역입니다. 다른 탐색·프로젝트·캘린더의 디자인·데이터는 유지합니다.
- 기본 열은 완료 체크 → 프로젝트 → 할 일 → 실제 마감 → 집중입니다. 행 높이 48px, 제목 14px, 프로젝트 13px이며 기존 다크 스타일을 재사용합니다. 실행 시간과 하위 항목은 행에 펼치지 않습니다.
- 완료 상태 탭과 정렬 아이콘, 기존 추가·타임라인 진입점을 유지합니다. 열 제목에서 프로젝트·이름 검색·마감 필터와 정렬을 열며 별도 필터 설명 줄을 만들지 않습니다.
- 제목/행 클릭은 오른쪽 380px 상세 패널, 집중 버튼은 실제 할 일 제목의 타이머 패널입니다. 타이머는 숫자를 눌러 분 단위 수정하며 시작·일시정지·종료는 접근성 이름을 가진 아이콘입니다. 다른 업무에 실행 중인 타이머가 있으면 먼저 종료합니다.
- 하위 할 일은 기존 checks를 사용하여 추가·수정·완료·휴지통 처리를 지원합니다. 메모는 버튼 없는 편집 영역에서 텍스트·이미지를 붙여넣고 선택·삭제합니다. 이미지 첨부는 2MB 이하, 파일 선택창을 열지 않습니다.
- 텍스트는 기존 notes와 검색·내보내기를 유지합니다. 안전한 텍스트/이미지 배열 memoParts와 기준 텍스트 memoText만 선택적으로 추가합니다. HTML을 그대로 저장하거나 실행하지 않습니다. 저장 실패 시 입력을 유지하고 오류를 알립니다.
- 완료·마감·시간 배치·프로젝트 관계·계정별 저장 키는 유지합니다. 가상 계정에서 필터·정렬, 하위 항목 변경, 이미지 붙여넣기/삭제 및 새로고침 보존, 타이머 중복 방지를 검수합니다.


적용일: 2026-10-16. 별도 업무 미리보기의 현재 구현 기준입니다.

앞으로의 작업 판단과 완료 기준은 [WORKING_RULES.md](WORKING_RULES.md)를 함께 따릅니다. 이 문서는 화면별 동작과 치수의 기준을 유지합니다.

## 콘텐츠 영역 통일과 프로젝트 2열 카드 (2026-10-26 최신 기준)

이 절은 콘텐츠 폭·프로젝트 목록에 관한 아래 과거 규칙보다 우선합니다.

- 오늘 할 일, 프로젝트 목록·상세, 캘린더는 기존 프로젝트·캘린더의 PC 최대 768px 콘텐츠 프레임을 공유합니다. 넓어진 오늘 화면을 이 폭에 맞추며 다른 화면을 확장하지 않습니다. 패널 안쪽 좌우 여백은 PC 28px, 720px 이하 18px, 440px 이하 12px입니다. 탭 이동 시 좌우 기준선이 바뀌지 않습니다. 월간은 기존 화면 높이 맞춤을 유지합니다.
- 프로젝트는 PC에서 2열, 720px 이하에서 1열입니다. 카드 간격은 PC 16px·모바일 12px, 안쪽 여백은 20px·18px입니다. 같은 행은 높이를 맞추고 긴 프로젝트명은 줄바꿈합니다.
- 프로젝트 목록은 화면 안에 패널 높이를 맞추고 콘텐츠 내부의 카드 영역만 세로 스크롤합니다. 상단 탐색과 정렬·필터·추가 도구는 고정합니다. 상세에서 목록으로 돌아오거나 화면을 갱신하면 목록의 스크롤 위치를 유지하며, 계정 변경 시 초기화합니다. 프로젝트 상세와 다른 화면의 스크롤 방식은 각 화면 기준을 따릅니다.
- 기본 카드에는 프로젝트명과 진행 중인 업무 묶음 이름만 표시합니다. 진행 중인 업무는 삭제되지 않은 `status: todo` 할 일이 하나 이상 속한 업무 묶음입니다. 대기·보류·완료·취소·삭제된 할 일은 판단에서 제외하며 같은 업무는 한 번만 표시합니다. 업무 묶음이 없는 할 일을 업무 이름으로 대신 표시하지 않습니다.
- 업무 이름은 두 개까지 표시하고 나머지는 `외 N개`로 나타냅니다. 긴 업무 이름은 말줄임하되 전체 제목을 툴팁과 접근 가능한 이름으로 제공합니다. 해당 업무가 없으면 `진행 중인 업무 없음`으로 표시하며 프로젝트를 숨기지 않습니다.
- 카드 전체를 누르면 기존 프로젝트 작업 페이지로 이동합니다. 전체 업무, 할 일, 마감, 다음 할 일, 개수와 프로젝트 정보는 그곳에 유지합니다. 목록의 정렬·상태 필터·추가도 유지합니다. 업무 이름 표시는 기존 데이터에서 계산하며 저장 스키마나 업무 상태를 변경하지 않습니다.

검증: `node --test --test-isolation=none tests/*.test.mjs`, 가상 계정 전용 `tests/work-project-grid-browser.cjs`로 화면별 폭·여백, 2열/1열, 완료 후 업무 제외·되돌리기, 필터·상세 접근과 월간 높이를 확인합니다.

## 오늘 할 일 집중 화면 (2026-10-26 최신 기준)

이 절은 아래 과거 기록과 충돌할 때 우선합니다. 사용자는 오늘 실행할 일을 먼저 읽고, 필요한 일만 시간을 배치하며, 자유롭게 설정한 타이머로 작업합니다.

- 오늘 할 일 / 프로젝트 / 캘린더 탐색과 상단 개인·업무 전환, 검색·알림·계정 기능을 유지합니다. 날짜 이동은 캘린더에서 하며 오늘 화면에는 기준 날짜만 표시합니다.
- 오늘 화면은 왼쪽 원형 타이머와 오른쪽 리스트 / 타임라인으로 구성합니다. 공통 PC 최대 폭 768px를 사용하며 720px 이하에서는 타이머를 위에 배치합니다. 할 일 제목은 16px, 프로젝트 > 업무는 위쪽 12px, 실제 마감은 오른쪽에 표시합니다. 오늘 시각 마감은 `16:00까지`로 표시합니다.
- 기본 목록은 오늘 작업 기간 또는 오늘 마감인 미완료 항목입니다. 기존 제외 날짜·수동 순서·필터를 존중합니다. 마감 지난 일, 다가오는 일·이전에 못 끝낸 일, 완료한 일은 접어서 접근합니다. 확인사항과 메모는 할 일 상세에 유지합니다.

이 절은 아래 과거 UI 기록과 충돌할 때 우선합니다. 기존 데이터·개인 일정·계정 저장 구조는 유지합니다.

## 업무 주간·월간 달력

- 요일은 일요일부터 토요일까지 표시합니다. 기존 개인 캘린더의 주 시작 설정은 유지합니다.
- 여러 날의 작업 계획은 한 주 안에서 높이 22px의 연속 막대로 표시하며, 주 경계에서만 나눕니다. 겹친 일정은 서로 다른 행에 배치합니다.
- 마감일은 작업 기간을 늘리지 않습니다. 작업 기간 안의 마감은 같은 막대에 날짜와 함께 표시하고, 기간 밖의 마감은 해당 날짜에 별도로 표시합니다.
- 월간은 3행까지 표시하고 초과 일정이 있는 날짜의 오른쪽 끝에 + 버튼을 표시합니다. 누르면 해당 날짜의 전체 일정 목록을 열고, 항목을 누르면 상세로 이동합니다. 주간은 모든 일정을 표시하며 내용에 따라 높이가 늘어납니다.
- 날짜별 추가 버튼은 빈 날짜에서는 날짜 바로 아래, 일정이 있으면 해당 날짜의 마지막 표시 막대 바로 아래에 놓습니다. 주간·월간 모두 마우스 호버 또는 키보드 포커스 때 표시합니다. 호버가 없는 터치 기기에서는 접근할 수 있도록 표시합니다.
- 월간 상단에 연·월과 이전 달 / 이번 달 / 다음 달 이동을 표시합니다.

## 목록 정렬과 간격

- 목록 카드는 체크박스·제목·마감·호버 추가 버튼을 한 행에서 중앙 정렬합니다. 확인사항은 제목의 왼쪽 선에 맞춰 다음 행에서 전부 표시합니다.
- 카드 최소 높이 74px, 안쪽 여백 위아래 20px·왼쪽 24px·오른쪽 18px, 카드 사이 10px. 480px 이하에서는 최소 높이 64px로 줄입니다.
- 확인사항은 제목의 시작 위치에 맞춥니다. 오른쪽 마감 열을 침범하지 않으며 입력창은 가용 폭 안에서 줄어듭니다.

## 리마인드 알림창

- 메인 목록에 리마인드 카드를 두지 않습니다. 상단 알림벨은 모든 업무 보기에서 실제 오늘(한국 시간)의 미확인 개수를 표시합니다. 조회 날짜·검색·필터는 알림 대상에 영향을 주지 않습니다.
- 계정 데이터가 준비된 뒤 해당 날짜 첫 접속에 한 번 자동으로 엽니다. 빈 상태는 자동으로 열지 않고 그날의 첫 조회로 기록합니다. 이후 새 항목·새로고침·보기 전환은 자동으로 열지 않으며 알림벨로 조회합니다.
- 편집·다른 팝업·백그라운드 상태에서는 자동 열기를 미룹니다. 다음 사용 시 재검사하며 입력을 덮어쓰지 않습니다. 자동 표시 이력은 브라우저 저장소에 계정별로 기록합니다. 다른 기기에서는 그 기기의 첫 접속에 열립니다.
- 알림벨 아래에 최대 420px 폭·560px 높이의 내용 크기 팝오버를 표시합니다. 좌우 16px를 확보하며 화면 하단 안으로 제한합니다. 내용은 세로 스크롤하고 각 행은 14px 세로 여백·12px 요소 간격을 사용합니다.
- 항목은 프로젝트/업무, 제목, 실제 마감 순서로 표시하고 마감순으로 정렬합니다. 제목은 줄바꿈하며 클릭하면 알림창을 닫고 상세로 이동합니다.
- ‘오늘’은 실제 오늘 계획에 추가하며 실제 마감·원본·기존 시간은 유지합니다. 중복 계획을 만들지 않습니다. ×는 오늘 리마인드만 확인 처리하며 원본을 삭제하거나 완료하지 않습니다. 되돌리기를 제공합니다.
- 창 닫기·바깥 클릭·Escape는 개별 확인 처리를 하지 않습니다. 이후 알림벨로 다시 열 수 있습니다. 미확인 항목이 없으면 배지를 숨기고 수동 열기에서 빈 상태를 표시합니다.
- 리마인드는 사용자가 직접 설정한 시작일이 도달한 미완료 항목만 표시합니다. 작업 예정일 경과나 오늘 마감이라는 이유로 알림을 자동 생성하지 않습니다. 오늘 목록과 알림은 별도로 판단하므로 알림 설정·확인이 할 일을 목록에서 없애지 않습니다. 오늘 계획이 있는 알림에는 ‘오늘 일정’을 표시합니다. 완료·취소·삭제 항목은 알리지 않습니다.
- 개별 확인과 오늘 계획은 기존 계정 저장·동기화를 사용하며, 알림창 새로고침만으로 업무 목록 전체를 다시 그리지 않습니다.

## 날짜 분류와 순서

- 지연은 실제 마감일·마감 시각으로 판정합니다. 날짜만 있는 마감은 다음 날부터 지연입니다. 오늘 하기로 했지만 내일 마감인 일에는 지연 배지를 붙이지 않습니다.
- 오늘 작업 기간에 포함된 일은 오늘 일정에 나타납니다. 실제 마감이 지났어도 오늘에 배치된 일은 여기서 지연 배지를 유지하고 아래 목록과 중복되지 않습니다.
- 작업 예정일이 지난 미완료 할 일은 실제 마감이 남아 있거나 없으면 오늘 목록에 계속 표시합니다. 원래 작업 기간·시간·마감을 자동 변경하지 않습니다. 이후 날짜로 다시 예약한 항목은 그 예약을 존중하며 앞당겨 표시하지 않습니다.
- 오늘이 실제 마감인 일도 오늘 목록에서 확인할 수 있습니다. 마감이 지나면 지연된 일정으로 분류하되 오늘 작업 기간에 포함된 항목은 오늘 목록에서 지연 표시를 유지합니다.
- 자동 정렬은 오늘의 시간 배치가 있는 항목을 시작 시간순으로 먼저 표시하고, 나머지를 실제 마감순으로 정렬합니다. 마감이 없으면 뒤에 둡니다.
- 카드 왼쪽의 호버 핸들을 드래그하면 해당 날짜만 수동 순서로 전환합니다. 지연된 일정을 오늘 목록으로 옮기면 오늘 계획을 추가하고 마감일과 지연 배지를 유지합니다. 필터의 ‘자동 정렬’로 되돌릴 수 있습니다.
- 터치에는 핸들을 표시합니다. 핸들 클릭 또는 Enter로 위치 선택 메뉴를 열어 키보드로도 이동합니다. 프로젝트·업무 묶기 상태에서 드래그하면 묶기를 해제하여 수동 순서를 명확히 표시합니다.
- 수동 순서는 날짜별 `dailyOrder`, 리마인드 확인은 `reminderAcknowledgedOn`에 저장합니다. 기존 데이터·백업에는 없어도 되는 선택 필드이며 기존 저장 키를 유지합니다.

## 바로 편집

- 상세 팝업은 내용 높이에 맞추고 화면의 가로·세로 중앙에 놓습니다. 최대 높이만 화면 안으로 제한하며, 내용이 길 때 팝업 내부에서 스크롤합니다. 닫기 영역 아래에 빈 공간을 남기지 않습니다.
- 제목·메모·사업비·확인사항 내용은 그 자리에서 입력합니다. 입력을 마치고 다른 곳으로 이동하거나 한 줄 입력에서 Enter를 누르면 저장합니다.
- 텍스트 입력 중 민트 테두리·외곽선은 표시하지 않습니다. 확인사항 추가 폼은 테두리 없이 입력란과 ‘저장·취소’를 표시합니다. 키보드로 이동하는 버튼에는 중립색 포커스를 유지합니다.
- 상태·진행 단계는 대기·진행중·완료·취소 라디오 버튼으로 바로 선택합니다. +에서 이름 입력 후 저장하면 새 항목을 등록하고 선택합니다. 상태 항목은 할 일 전체에서, 진행 단계는 같은 프로젝트의 업무·프로젝트에서 재사용합니다. 프로젝트 없는 업무의 단계도 재사용합니다. 기존 단계와 보류 상태는 유지하며, 새 상태는 완료·취소로 간주하지 않습니다. 별도의 전체 수정 모드는 없습니다.
- 관련 업무·프로젝트는 값 바로 아래의 드롭다운에서 검색·선택·연결 해제합니다. 검색한 이름으로 새 항목을 만들어 바로 연결할 수 있습니다. 바깥 클릭·Esc로 닫고 방향키로 선택합니다. 옆 화살표는 해당 상세로 이동합니다.
- 할 일 상세 제목 왼쪽에 완료 체크박스를 표시하고 상태 선택과 즉시 동기화합니다. 상단 종류 이름은 14px로 표시합니다. ‘저장됨’과 하단 ‘변경사항 자동 저장’ 문구는 생략하며 실제 자동 저장과 저장 실패 경고는 유지합니다.
- 상세 확인사항은 다른 속성과 같은 라벨·내용 열에 배치하고 별도 구분선을 표시하지 않습니다.
- 날짜 값을 한 번 누르면 바로 달력이 열립니다. 상단 날짜 입력, 월 이동·오늘, 날짜 격자, 관련 옵션을 한 팝오버에 표시합니다. 단일 날짜는 클릭 즉시 저장하고, 기간은 시작·종료 날짜를 선택하면 저장합니다. 별도 완료 버튼은 없습니다.
- 작업·사업 기간은 ‘종료일’ 스위치로 단일 날짜와 기간을 전환합니다. 날짜 직접 입력은 YYYY. MM. DD., YYYY-MM-DD, YYYY/MM/DD 형식을 지원하며 유효하지 않은 날짜는 저장하지 않습니다. 기존 시간 배치가 작업 기간 밖으로 벗어나는 변경은 거절하여 시간을 조용히 삭제하지 않습니다.
- 실제 마감 달력에는 ‘시간 포함’과 리마인드 시작일(당일·1일 전·2일 전·1주 전)을 제공합니다. 기존 작업 시간 배치는 별도 10분 블록 기능을 유지합니다. 리마인드는 화면에 표시할 시작일이며 외부 알림 발송을 추가하지 않습니다.
- 날짜 형식은 년/월/일 또는 상대 표시로 선택하며 상세 화면의 표시만 변경합니다. ‘삭제’는 선택한 날짜 속성을 비우며 항목 원본을 삭제하지 않습니다. 바깥 클릭·닫기·Esc로 팝오버를 닫습니다.
- 관련 인원과 태그는 같은 칩 방식입니다. 기존 이름을 검색해 선택하거나 새 이름을 입력하고 Enter로 추가하며, 칩의 ×로 해당 연결만 제거합니다. 할 일·업무·프로젝트 모두 여러 인원을 등록할 수 있습니다. 중복은 합치고, 기존 문자열 인원은 쉼표·줄바꿈 기준으로 표시하되 이름 안의 공백은 유지합니다.
- 확인사항 추가 입력창은 기본적으로 숨기고 공간도 차지하지 않습니다. 할 일 카드(상세에서는 확인사항 영역)에 호버하거나 키보드로 포커스하면 + 버튼이 나타납니다. 클릭하면 해당 항목의 입력창만 열립니다. 터치 화면에는 작은 + 버튼을 제공합니다.
- Enter 또는 저장 버튼으로 등록하면 입력창은 닫힙니다. 취소 또는 Esc로 취소합니다. 빈 입력은 항목으로 만들지 않습니다. 기존 확인사항은 개수와 무관하게 전부 펼쳐 표시하며 이름 수정·체크·삭제가 가능합니다. +1개·더 보기·접기 기능은 사용하지 않습니다.
- 체크박스 크기는 체크박스에만 적용합니다. 확인사항 텍스트 입력은 최소 28px 높이와 1.5 줄 높이를 확보하며, 추가 입력은 최소 32px 높이로 표시합니다.
- 목록 하단 가운데 42px 원형 +를 누르면 한 줄 입력창이 열립니다. 이름 입력 후 Enter 또는 저장으로 할 일을 만들고, 취소 또는 Esc로 취소합니다. 입력 중에는 분 단위 화면 갱신을 멈춰 초안을 보존합니다. 업무·프로젝트에서도 목록 하단 +로 항목을 추가합니다. 상세에서는 필요한 속성만 채웁니다.
- 업무 상세의 별도 ‘할 일 완료율’ 속성은 표시하지 않습니다. 목록 제목에 ‘할 일 완료 수/전체 수’를 표시하며 삭제된 항목은 집계에서 제외합니다. 업무 상세 하단의 ‘변경사항 자동 저장’ 문구는 생략하고 자동 저장 동작은 유지합니다.
- 삭제한 할 일·업무·프로젝트·확인사항은 설정의 휴지통에서 복구합니다. 상위 항목 삭제 시 하위 기록을 삭제하지 않고 관계를 해제합니다. 복구 시 사용자가 새로 연결한 관계는 덮어쓰지 않습니다.

## 10분 시간 블록

- 팝업 제목은 해당 할 일 이름이고 본문 소제목은 ‘시간 배치’입니다. ‘시간 선택’ 안내와 블록 설명·하단 범례는 표시하지 않습니다.
- 업무 시간 격자는 08:00~19:00을 10분 단위로 표시합니다. 오늘 날짜에서는 한국 시간의 현재 블록으로 스크롤·키보드 포커스를 맞춥니다. 다른 날짜는 기존 배치 또는 첫 시간으로 엽니다.
- 완전히 지난 블록은 흐리게 표시하지만 클릭과 범위 포함은 허용합니다. 현재 블록은 중립색 테두리로 표시하며, 선택된 지난 블록은 선택 상태가 선명하게 보입니다.
- 첫 블록과 마지막 블록을 클릭하면 양 끝을 포함하는 연속 구간이 선택됩니다. 역순 선택도 지원합니다.
- 한 칸만 선택하고 저장하면 10분입니다.
- 선택한 뒤 소제목 옆에 구간·총 소요 시간을 간결하게 표시하고 ‘저장’으로 확정합니다. 닫으면 저장하지 않습니다.
- 다른 할 일과 겹치는 블록은 무늬로 표시하며, 선택 후 겹치는 할 일 이름을 안내합니다. 겹침 자체를 금지하지는 않습니다.
- 날짜별 한 구간을 배치합니다. 같은 날짜에 다시 저장하면 이전 구간을 바꿉니다. 실제 마감일은 변경하지 않습니다.
- 배치 종료가 실제 마감을 넘으면 편집기에서 경고하고, 목록·타임라인에도 경고 표시를 제공합니다. 임의로 시간을 옮기거나 마감을 변경하지 않습니다.
- 기존에 10분 경계가 아닌 시간이 있으면 격자 경계로 제안하며, 저장하기 전에는 원본을 변경하지 않습니다.

## 저장과 구현 경계

이 화면은 기존 개인 일정과 동일한 계정으로 저장·동기화합니다. 개인 일정은 `myWeekV1`, 업무는 `myWorkV1`에 분리해 저장하며 다른 영역을 덮어쓰지 않습니다. 로그인 전에는 업무 백업을 이 브라우저에 보관할 수 있고, 로그인한 계정을 확인한 뒤 가져오기를 실행합니다. 계정 전환 시 이전 계정의 편집 화면과 데이터를 비웁니다. 저장 실패는 경고로 표시하고 입력과 재시도할 데이터를 보존합니다.

- `focus.css`: 집중 레이아웃과 글자·상세·시간 블록 표현
- `layout.css`: 최신 상단·평면 목록·검색·필터·드래그 표시
- `reminders.js`, `reminders.css`: 실제 오늘의 알림벨·첫 접속 판단·알림창
- `work-view.js`: 날짜별 분류·정렬·검색·필터·퇴근 카운트
