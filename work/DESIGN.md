# 업무 화면 현재 UX 규격

이 문서만 현재 화면 규격으로 사용합니다. 변경 전 내용은 [2026-10-27 이력](docs/history/2026-10-27-DESIGN.md)에 보관합니다. 이력의 수치나 구성을 새 구현에 적용하지 않습니다.

## 기준의 성격
- **확정 요구**: 대화에서 사용자가 지정하거나 승인한 동작·스타일입니다.
- **구현값**: 별도 사용자 지정이 없는 역할별 치수입니다. 기존 구현을 통합한 값이며 사용자 확정값으로 표현하지 않습니다. 변경할 때 이유·영향 화면을 검수 기록에 남깁니다.
- 작업 절차·데이터 보호는 [WORKING_RULES.md](WORKING_RULES.md)를 따릅니다.

## 기본 방향 — 확정 요구
기존 다크 스타일을 유지합니다. 중복 제목·긴 설명·불필요한 장식을 제거하되 수정·삭제·상세 진입점을 남깁니다. 같은 역할은 탭이 달라도 같은 표현과 조작을 사용합니다.

## 역할별 치수

공통 토큰은 common-ux.css의 :root에 둡니다. 팝업이 #app 밖에 있어도 같은 값을 상속합니다. 캘린더 날짜 셀·시간 블록은 일반 테이블 행 높이를 적용하지 않습니다.

## 목록 공통 — 확정 요구
- 모든 헤더는 **텍스트 자체**를 열 중앙에 맞춥니다. 화살표는 옆에 겹쳐 배치하여 표시 전후 중심이 변하지 않습니다. 호버·포커스·열림에서 표시하고 터치에서는 항상 표시합니다.
- 긴 프로젝트명·업무명·할 일은 왼쪽, 현황·날짜·시간·체크·동작은 가운데, 셀은 세로 가운데입니다.
- 모든 표에 가로·세로 1px 구분선과 스크롤 시 고정 헤더를 적용합니다. 헤더 열 경계 드래그·키보드 좌우·더블클릭 초기화를 지원합니다. 너비는 브라우저 설정이며 업무 데이터와 분리합니다.
- 상태는 기본 전체. 전체/미완료/완료 공통 메뉴를 사용하며 프로젝트·업무의 취소 조회는 유지합니다.
- 필요한 검색·필터·정렬을 헤더와 정렬 아이콘에서 제공합니다. 남은 할 일도 독립 필터·정렬이 있습니다. 필터 결과 없음과 원본 없음은 구분합니다.
- 제목 클릭은 인라인 편집. Enter/포커스 이동 저장, Escape 원복, 조합 중 Enter 무시. 별도 활성 배경·테두리를 추가하지 않습니다.
- 모든 할 일 테이블의 상세 아이콘은 행 오른쪽 끝에 상시 표시하고, 삭제는 바로 왼쪽에 호버·포커스·터치 시 표시합니다. 제목 영역에 동작 아이콘을 넣지 않습니다. 같은 16px 아이콘/32px 클릭 영역입니다. 프로젝트명에도 삭제 진입점이 있습니다.
- 프로젝트·작업 시작·마감 셀은 해당 위치에서 편집합니다. 기본 빈 값은 작은 `-`, 선택 입력의 빈 값은 `선택` 또는 `설정`입니다.
- 기본 내부 스크롤은 max-height min(60dvh,560px). 프로젝트 목록·업무 상세는 가용 높이를 사용합니다. 좁은 화면에서는 표 내부만 가로 스크롤합니다.

## 공통 메뉴·날짜·아이콘
- 탐색은 텍스트, 오늘 리스트/타임라인은 아이콘, 도구는 아이콘, 선택값은 텍스트+화살표입니다. 아이콘에 접근 가능한 이름과 툴팁을 제공합니다.
- 선택 메뉴는 공통 다크 표면·8px 모서리·6px 외곽 여백·최소 32px 항목·좌우 8px·12px/400 텍스트를 사용합니다.
- 좁은 현황 열의 선택 버튼은 좌우 6px·화살표 간격 4px로 줄이고 현황명은 줄바꿈하지 않습니다. 메뉴 항목 규격은 동일합니다.
- 선택 표시·방향키·Home/End·Escape·바깥 클릭·포커스 복귀를 공유합니다. 표 안의 메뉴도 스크롤에 잘리지 않도록 화면 경계에 배치합니다.
- 달력은 date-picker.js를 공통 사용합니다. 날짜는 월/일(요일), 다른 연도는 연도 포함. 마감 표시 형식으로 오늘/D-n/D+n을 선택할 수 있습니다. 마감 시간은 선택 사항입니다.
- 리마인드는 시작일과 선택 종료일을 설정합니다. 작업 시작·마감과 혼동하지 않습니다.

## 화면별 정보 구조
| 화면 | 기본 표시와 행동 |
|---|---|
| 오늘 할 일 | 상단 주요 탭 오른쪽에 리스트/타임라인. 그 아래 한 줄의 왼쪽에 프로젝트 탭, 오른쪽에 좁은 조회 범위·완료 상태·정렬·추가. 좁은 화면에서만 도구 줄바꿈. 중복 제목·날짜 없음. 전체는 체크/프로젝트/할 일/작업 시작/마감/집중/동작 표, 프로젝트 선택 시 해당 항목만 조회하고 프로젝트 열 숨김 |
| 남은 할 일 | 오늘 목록에 없는 모든 미완료 항목(미정·미래 포함)을 중복 없이 보여주는 별도 영역. 작은 제목·개수와 독립 필터·정렬. 오늘 하기 아이콘 다음에 오른쪽 끝 상세·삭제 동작. 상단 프로젝트 선택을 동일하게 적용 |
| 타임라인 | 현재 계획을 시간축으로 표시. 제목은 공통 상세, 시간은 배치 편집. 상시 원형 타이머 없음 |
| 프로젝트 목록 | 현황/프로젝트명/진행중인 업무/마감일/사업 종료일. 업무별 마감일 대응. 무의미한 이동 화살표 없음 |
| 프로젝트 상세 | 제목·현황·사업 기간, 접힌 보조 정보, 업무-할 일 계층 표. 중복 프로젝트 상세 없음. 진행단계 선택·할 일 상태 열 없음 |
| 업무 상세 | 업무명·닫기, 완료 수·상태·추가, 하위 할 일 표만 표시. 과거 마감·메모·단계 데이터는 보존 |
| 할 일 상세 | 체크·줄바꿈 제목·닫기, 프로젝트·업무·작업 시작·마감·리마인드, 전체 폭 하위 할 일·텍스트 메모, 접힌 기타 정보. 다른 상세로 재진입하지 않음 |
| 캘린더 | 공통 날짜 선택·필터·보기 전환. 작업 일정과 실제 마감의 표시 의미 분리. 월간 초과 일정은 더보기에서 확인 |

프로젝트 현황은 목록과 상세에서 수정할 수 있고, 은은한 진행중 청색/완료 녹색/보류 황색/취소 적색으로 구별합니다. 현황 헤더에는 점이 없습니다. 프로젝트 상태 변경 시 기존 미완료 일정 처리 선택은 유지합니다.

## 프로젝트 탭
- 목록 도구줄 왼쪽에 `[전체][프로젝트…]`를 배치합니다. 프로젝트가 많으면 탭 영역만 가로 스크롤하고 오른쪽 도구는 유지합니다. 탭 끝 +의 공통 메뉴에서 검색·체크하여 표시할 프로젝트를 넣고 뺍니다. 프로젝트 자체를 생성·삭제하는 동작과 구분합니다.
- 최초에는 진행 중 프로젝트 최대 4개를 표시합니다(구현 기본값). 이후 사용자가 선택한 탭은 계정별 브라우저 설정으로 저장하며 다른 계정과 섞지 않습니다.
- 선택 프로젝트는 오늘/남은 할 일/타임라인에 함께 적용합니다. 업무를 통해 연결된 할 일도 포함합니다. 전체로 돌아오면 프로젝트 열을 복원합니다.
- 탭 전환 중 미저장 제목은 프로젝트별로 보존하고 다른 프로젝트에 잘못 등록하지 않습니다. 탭 제거는 데이터 삭제가 아닙니다.

## 추가와 날짜 기본값 — 확정된 동작
- 표 끝의 여백에 왼쪽 정렬 `+ 할 일 추가` 클릭 영역(24px)을 둡니다. 데스크톱은 호버·키보드 포커스에 표시하며 레이아웃 공간을 추가하지 않습니다. 터치는 44px 영역으로 상시 표시합니다. 가로선과 중앙 + 장식은 사용하지 않습니다. 빈 목록은 전체 빈 영역이 `+ 할 일 추가` 버튼이며 클릭·Enter로 입력 행을 엽니다. 입력 중에는 빈 안내와 추가 진입점을 숨깁니다. 프로젝트·제목·마감 입력은 실제 열 경계에 맞추고 열 너비 변경에도 함께 움직입니다. 입력 행은 제목만 입력합니다. 업무 없음·작업 시작·날짜 유지 및 마감 선택 옵션을 표시하지 않습니다. 필요한 속성은 생성 후 열 또는 상세에서 수정합니다. 상단 +도 같은 입력 행을 엽니다.
- 제목만으로 등록할 수 있습니다. Enter 저장 후 다음 입력, 여러 줄은 줄마다 항목, Shift+Enter 줄바꿈. 현재 선택한 프로젝트 또는 열린 업무 연결은 연속 유지합니다. 전체에서 추가하면 프로젝트 미연결입니다.
- 날짜 미지정 추가의 시작일은 오늘입니다. 오늘/타임라인은 보고 있는 날, 캘린더는 선택한 날을 사용합니다. 프로젝트·업무도 오늘로 시작합니다. 추가 행에 날짜 설정 컨트롤은 표시하지 않습니다. 시작 예정·미정·완료 필터에서 추가해도 등록 후 오늘/전체 상태로 전환해 방금 추가한 항목을 보여줍니다. 마감 기본값은 항상 없음입니다.
- 연속 등록도 생성 위치의 날짜 기본값을 적용합니다.
- 프로젝트 안에서는 프로젝트, 업무 안에서는 업무와 연결 프로젝트를 이어받습니다. 프로젝트 탭 선택은 명시적 추가 대상으로 사용합니다. 헤더의 임시 필터만으로는 관계를 부여하지 않습니다.
- 빈 입력에서 Escape로 닫습니다. 바깥 클릭·재렌더로 작성 중 초안을 버리지 않습니다. 저장 실패 재시도는 중복 생성하지 않습니다.
- 시작일 이후 미완료는 오늘 목록에 남습니다. 마감이 지난 것과 작업 시작은 별도입니다. 미래 시작은 오늘 목록에서 제외합니다.

## 집중·메모
- 집중 아이콘으로 패널만 열고 자동 시작하지 않습니다. 제목은 실제 할 일 이름. 조작은 아이콘이며 10/20/30/60분과 직접 입력을 제공합니다.
- 패널 닫기·탭 이동으로 타이머를 초기화하지 않습니다. 실행 중 닫으면 미니 바, 패널과 미니 바는 중복 표시하지 않습니다. 종료가 할 일을 완료시키지 않습니다.
- 업무 메모는 텍스트 입력만 제공합니다. 이미지 삽입 기능은 제거하되 기존 첨부 데이터는 유지합니다.

## 구현 소유권
| 역할 | 파일 |
|---|---|
| 공통 토큰·리스트·메뉴·패널·반응형 | common-ux.css |
| 화면 프레임·공통 인셋 | content-layout.css |
| 아이콘·버튼·선택 메뉴 렌더러 | ui-components.js |
| 메뉴 열기·닫기·키보드·위치 | surface-interactions.js |
| 상태 옵션 / 날짜 / 열 조절 | status-filter.js / date-picker.js / table-resize.js |
| 행 추가 / 통합 상세 | task-composer.js / detail-ui.js |

기존 화면 CSS는 각 화면 고유 구조만 담당합니다. 공통 크기나 메뉴를 새 화면 파일에서 재정의하지 않습니다. 기존 파일의 호환 규칙을 수정할 때는 실제 계산 스타일을 비교합니다. 검수 기록은 [tests/ux-review.md](../tests/ux-review.md)에 둡니다.
