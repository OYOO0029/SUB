# 업무 화면 현재 UX 규격

이 문서만 현재 화면 규격으로 사용합니다. 변경 전 내용은 [2026-10-27 이력](docs/history/2026-10-27-DESIGN.md)에 보관합니다. 이력의 수치나 구성을 새 구현에 적용하지 않습니다.

## 기준의 성격
- **확정 요구**: 대화에서 사용자가 지정하거나 승인한 동작·스타일입니다.
- **구현값**: 별도 사용자 지정이 없는 역할별 치수입니다. 기존 구현을 통합한 값이며 사용자 확정값으로 표현하지 않습니다. 변경할 때 이유·영향 화면을 검수 기록에 남깁니다.
- 작업 절차·데이터 보호는 [WORKING_RULES.md](WORKING_RULES.md)를 따릅니다.

## 기본 방향 — 확정 요구
기존 다크 스타일을 유지합니다. 중복 제목·긴 설명·불필요한 장식을 제거하되 수정·삭제·상세 진입점을 남깁니다. 같은 역할은 탭이 달라도 같은 표현과 조작을 사용합니다.

## 목록 공통 — 확정 요구
- 기본 열은 완료 체크 / 할 일 / 유형 / 프로젝트 / 작업일자 / 행 버튼. 프로젝트 선택 시 프로젝트 열을 숨깁니다. 기한 지난 일만 지연일수 열을 추가합니다.
- 할 일·프로젝트 헤더는 본문과 동일한 왼쪽 정렬, 날짜·상태·동작은 가운데 정렬. 헤더 아이콘 자리는 텍스트 정렬을 바꾸지 않습니다.
- 행은 한 줄, 제목 옆 업무명·설명·태그·체크리스트 집계를 붙이지 않습니다. 옅은 가로 구분선 중심이며 세로 구분선은 줄입니다. 헤더 고정·열 크기 조절을 유지합니다.
- 체크와 오른쪽 끝 ⋯ 상세는 항상 표시. 집중·삭제·체크 왼쪽 이동 손잡이는 호버/포커스 시 표시하며 공간은 항상 확보합니다. 터치는 동작을 바로 표시합니다.
- 할 일 상태 선택·상태 필터는 표시하지 않습니다. 체크로 완료, 해제로 미완료만 조작합니다. 할 일·프로젝트·작업일자 헤더는 일반 텍스트이며 검색·필터·정렬 메뉴를 열지 않습니다.
- 제목은 인라인 편집, Enter/포커스 이동 저장, Escape 원복, 한글 조합 Enter 무시. 별도 활성 장식 없음.
- 오늘 직접 정렬은 전체 프로젝트·필터 없음·직접 정렬에서만 가능. todayOrder로 계정 데이터에 저장하고 프로젝트/기존 일별 순서와 분리합니다. 키보드 Alt+위/아래 및 손잡이의 이동 메뉴도 제공합니다.
- 오늘 할 일이 주 화면이며 남은/기한 지난 일은 보조 목록입니다. 오늘 화면 프로젝트 필터 탭 오른쪽에 미완료/완료 포함 선택과 정렬을 한 번만 제공합니다. 체크형 완료 보기 토글은 사용하지 않습니다. 탭만 가로 스크롤하며 760px 이하에서는 도구가 다음 줄 오른쪽으로 이동합니다. 정렬(직접 정렬/마감 빠른순/최근 추가순/프로젝트순)은 각 목록 내부에 공통 적용하며 오늘→남은→기한 지난 순서를 유지합니다. 완료 항목은 선택 시 맨 아래 별도 목록에 표시하며 추가 행은 제공하지 않습니다. 프로젝트 할 일에도 동일한 완료 보기·정렬을 제공합니다. 전체 조회는 프로젝트 화면에서 제공합니다.

## 반응형 — 구현값
- 600px 이하 할 일 목록은 첫 줄 체크·제목·상세 ⋯, 둘째 줄 프로젝트·작업일자로 배치합니다. 날짜 미정은 표시하지 않습니다. 모바일 표 헤더는 숨기며 완료 보기·정렬은 PC와 같은 공통 도구를 사용합니다. 표 테두리·헤더 배경은 제거합니다. 제목은 한 줄 편집을 유지하고 긴 내용은 상세 패널에서 확인합니다.
- 모바일은 상세 ⋯만 항상 표시하며 44px 클릭 영역을 확보합니다. 집중·오늘 하기/오늘에서 빼기·삭제는 상세 패널에서 제공합니다. 열 조절은 PC에서 제공하고 저장한 열 너비는 보존합니다.
- 태블릿 표와 WBS·캘린더는 화면 전체가 아닌 콘텐츠 영역 안에서 스크롤합니다. 가로 프로젝트 탭은 한 줄 스크롤을 유지합니다.
- 580px 이하 상세는 화면 폭·높이에 맞추고 내부를 스크롤합니다. 하단 안전 여백을 적용합니다. 추가 폼은 세로 배치하며 입력 높이만큼 목록이 늘어납니다.

## 공통 메뉴·날짜·아이콘
- 탐색은 텍스트, 오늘 목록은 기본이고 타임라인 열기만 아이콘, 도구는 아이콘, 선택값은 텍스트+화살표입니다. 아이콘에 접근 가능한 이름과 툴팁을 제공합니다.
- 프로젝트 소속 변경·추가·상세는 project-picker.js 공통 팝오버를 사용합니다. 배경을 가리지 않고 최근 선택 최대 5개를 먼저 표시합니다. 최근 선택이 없으면 진행 프로젝트 최대 5개를 바로 표시합니다. 프로젝트 항목은 폴더 아이콘, 목록 확장은 테두리 버튼, 포함 옵션과 연결 해제는 구분선으로 구별합니다. 검색은 입력 DOM과 한글 조합·커서를 유지한 채 결과만 갱신합니다. 검색 또는 프로젝트 더 보기로 후보를 확장하며 완료·취소·보류는 포함 옵션으로만 노출합니다. 최근 선택은 계정별 브라우저 설정에 저장합니다. 연결 해제는 기존 소속이 있을 때만 메뉴 하단에 표시하며 미연결 셀은 -로 표기합니다.
- 선택 메뉴는 공통 다크 표면·8px 모서리·6px 외곽 여백·최소 32px 항목·좌우 8px·12px/400 텍스트를 사용합니다.
- 좁은 현황 열의 선택 버튼은 좌우 6px·화살표 간격 4px로 줄이고 현황명은 줄바꿈하지 않습니다. 메뉴 항목 규격은 동일합니다.
- 선택 표시·방향키·Home/End·Escape·바깥 클릭·포커스 복귀를 공유합니다. 표 안의 메뉴도 스크롤에 잘리지 않도록 화면 경계에 배치합니다.
- 달력은 date-picker.js를 공통 사용합니다. 날짜는 월/일(요일), 다른 연도는 연도 포함. 마감 표시 형식으로 오늘/D-n/D+n을 선택할 수 있습니다. 마감 시간은 선택 사항입니다.
- 리마인드는 시작일과 선택 종료일을 설정합니다. 작업 시작·마감과 혼동하지 않습니다.

## 화면별 정보 구조
| 화면 | 구성 |
|---|---|
| 오늘 할 일 | 명시적으로 오늘 선택한 미완료 중 기한이 지나지 않은 항목 |
| 남은 할 일 | 오늘 선택하지 않은 미완료 중 기한이 지나지 않은 항목 |
| 기한 지난 일 | 작업일자의 마지막 날짜가 지난 미완료 전체. 가장 아래, 중복 없이 표시 |
| 프로젝트 목록 | 현황 / 프로젝트명 / 진행 중인 업무 / 사업 종료일 / 남은 할 일. 진행 프로젝트 기본, 전체·완료·보류·취소 필터 및 전체 할 일 진입점. 이름 클릭 상세, 업무 클릭 업무별 보기 |
| 프로젝트 / 할 일 | 업무 구분 없는 평평한 목록. 추가·완료·작업일자 편집 |
| 프로젝트 / 일정(WBS) | 프로젝트 → 업무까지만. 업무 생성·기간 편집. 할 일 행을 섞지 않음 |
| 프로젝트 / 업무별 보기 | 선택한 할 일이 있을 때만 연결/해제 도구. 새 업무 입력은 별도 접기. 업무명·개수 → 연결 할 일 → 접힌 태그·결과 메모 순서. 공통 입력/버튼 사용 |
| 할 일 상세 | 제목·프로젝트·작업일자·메모. 내용 있는 체크리스트만 접힌 보조 영역. 업무 연결 편집 없음 |
| WBS 상세 | 업무명·업무 기간·기존 진행 단계 선택·접힌 연결 할 일 목록. 연결 편집 없음 |
| 캘린더 | 기존 일정/마감 표시 보존. 새 작업일자는 기간으로 조회 |

오늘 선택은 todaySelected이며 날짜를 변경하지 않습니다. 시작일에 따른 자동 추가는 없습니다. 선택은 다음 날에도 유지되며 기한이 지나면 기한 지난 일로 이동합니다. 날짜 미정은 기한 초과가 아닙니다. 완료/취소/삭제는 오늘 세 영역에서 제외합니다.

업무와 할 일 기간은 독립이며 연결/삭제가 날짜를 바꾸지 않습니다. 업무를 삭제하면 할 일은 원래 프로젝트 미분류로 남습니다. 업무로 묶어도 동일 ID를 사용하고 복제하지 않습니다. 연결 할 일이 업무 기간을 벗어나면 경고 아이콘과 호버·포커스·탭 설명만 표시하고 저장은 허용합니다.

## 프로젝트 탭
- 오늘 화면 목록 도구줄 왼쪽에 `[전체][프로젝트…]`를 배치합니다. 프로젝트 화면은 가로 탭 대신 프로젝트 목록 → 상세로 이동하며 오늘 필터와 독립입니다. 프로젝트가 많으면 탭 영역만 가로 스크롤하고  탭 끝 +의 공통 메뉴에서 검색·체크하여 표시할 프로젝트를 넣고 뺍니다. 프로젝트 자체를 생성·삭제하는 동작과 구분합니다.
- 완료·취소·보류 프로젝트는 선택 후보와 가로 탭에서 기본 숨김이며 포함 옵션으로 표시합니다. 기존 소속과 핀 데이터는 삭제하지 않습니다. 최초에는 진행 중 프로젝트 최대 4개를 표시합니다(구현 기본값). 이후 사용자가 선택한 탭은 계정별 브라우저 설정으로 저장하며 다른 계정과 섞지 않습니다.
- 선택 프로젝트는 오늘/남은/기한 지난 일/완료한 일/타임라인에 함께 적용합니다. 업무를 통해 연결된 할 일도 포함합니다. 전체로 돌아오면 프로젝트 열을 복원합니다.
- 탭 전환 중 미저장 제목은 프로젝트별로 보존하고 다른 프로젝트에 잘못 등록하지 않습니다. 탭 제거는 데이터 삭제가 아닙니다.

## 추가와 날짜 기본값 — 확정 요구
- 목록 마지막에 낮은 강조의 + 할 일 추가를 항상 표시합니다. 빈 목록에서도 표시합니다. 입력 행은 실제 열 경계에 맞춥니다.
- 프로젝트 선택 버튼은 한 줄 말줄임과 고정 화살표 영역을 사용합니다. PC 추가 행은 기존 행 높이에 맞추며 완료·취소·보류 포함 옵션은 프로젝트 선택 메뉴 안에 둡니다.
- Enter 저장 후 입력을 비우고 포커스 및 프로젝트를 유지합니다. 여러 줄 붙여넣기는 여러 항목. 프로젝트 미선택도 저장할 수 있으며 목록의 프로젝트는 -로 표시합니다.
- 오늘 목록 추가는 todaySelected=true, 나머지 목록 추가는 false. 기한 지난 목록에서 날짜 없이 추가한 항목도 날짜 규칙에 따라 남은 할 일로 표시합니다. 작업일자 기본값 없음. 업무는 자동 생성하지 않습니다.
- 사용자에게는 완료 체크만 제공합니다. 호환 저장은 새 항목/완료 해제 waiting, 체크 done을 유지하며 진행 상태를 직접 선택하는 UI는 제거합니다. 날짜·타이머는 상태를 변경하지 않습니다. 기존 사용자 정의 상태/취소/보류는 보존합니다.
- 작업일자는 단일 날짜 또는 기간이며 workPeriod에 저장합니다. 마지막 날을 기한으로 사용합니다. 명시적 날짜 편집 시 기존 startDate/due 호환 필드도 반영합니다. 시작>종료는 오류와 함께 저장 차단.
- 과거 날짜·plans·blocks·체크리스트는 읽을 때 수정하지 않습니다. workPeriod가 없는 기존 데이터는 시작일/마감일/활성 계획을 읽어 표시합니다. 과거 시작일을 오늘 선택으로 추정하지 않습니다.
- 저장 실패는 입력과 생성된 항목을 유지하여 재시도 시 중복 생성하지 않습니다. Enter 연타/IME 조합 확정은 중복 저장하지 않습니다. 프로젝트 전환 초안은 소속별로 분리합니다.

## 기본 노출과 옆 패널
- 오늘/남은/기한 지난 일은 이 순서로 각각 접을 수 있습니다. 오늘 하기/오늘에서 빼기는 행 호버·포커스(터치는 상시)에서 제공합니다.
- 퇴근까지 남은 시간은 기본 ON. 설정의 표시 체크박스로 변경하고 브라우저 재접속 후에도 유지합니다. 저장 실패를 알립니다.
- 목록 헤더는 본문보다 낮은 강조(#9aa3af), 본문과 가까운 배경, 34px 높이로 통일합니다. 할 일 제목은 14px/500을 유지합니다.
- 일반 상세는 제목(할 일 완료 체크 포함) → 오늘 선택·집중 → 속성 → 메모 순서이며 상단에 넓게 보기·더보기·닫기를 둡니다. 제목은 여러 줄 자동 확장, 메모는 테두리 없는 본문입니다. 모달 배경 없이 하나의 옆 패널을 목록 위에 겹쳐 표시하고 항목 선택 시 교체합니다. 상세 열림·닫힘·확장에 따라 본문 폭·좌표·여백을 변경하지 않습니다. 편집 필드는 전환 전에 저장하고 저장 실패 중 전환을 막습니다.
- 프로젝트의 진행 중인 업무는 기존 stage가 진행/진행 중/실행/개발 중 계열인 업무만 표시합니다. 할 일 상태로 추정하거나 기존 데이터를 변환하지 않습니다. 복수는 첫 업무명 외 N개, 없으면 -입니다.
- 프로젝트 선택 시 이름·상태·기간 다음에 보기 탭과 할 일을 배치하고 사업비·인원·메모는 프로젝트 정보에 접습니다.
- 할 일 리마인드와 시간 배치는 메모 아래 속성 행으로 바로 표시하고 추가 설정 토글을 사용하지 않습니다. 시간별 보기의 시간 미정은 기본 펼침.

## 집중·메모
- 집중 아이콘으로 패널만 열고 자동 시작하지 않습니다. 제목은 실제 할 일 이름. 조작은 아이콘이며 10/20/30/60분과 직접 입력을 제공합니다.
- 집중 패널은 작은 크기로 제목·시간·시작/정지만 표시하며 삭제·하위 할 일·업무 상세는 표시하지 않습니다. 패널 닫기·탭 이동으로 타이머를 초기화하지 않습니다. 실행 중 닫으면 미니 바, 패널과 미니 바는 중복 표시하지 않습니다. 종료가 할 일을 완료시키지 않습니다.
- 업무 메모는 텍스트 입력만 제공합니다. 이미지 삽입 기능은 제거하되 기존 첨부 데이터는 유지합니다.

## 할 일 유형
- 할 일당 하나, 미지정 허용(-). 기본 수정/신청/보완/작성/회신/전달/확인/디자인/검수/결재. 제목 자동 분류 없음.
- 공통 목록 유형 셀과 상세에서 선택. 이름 대신 typeId로 연결하며 유형 목록 taskTypes는 기존 업무 계정 저장 경로로 보관합니다. 기존 데이터는 읽을 때 변경하지 않습니다.
- 유형 관리에서 추가/이름 변경/위아래 순서/삭제. 공백·대소문자 중복 방지, 최대24자. 사용 중 삭제는 사용 수를 표시하고 다른 유형 또는 미지정으로 명시적으로 대체합니다. 삭제된 할 일도 연결 대체하여 복원 후 끊긴 참조를 방지합니다.
- 저장 실패는 변경을 되돌리고 입력·오류를 남깁니다. 모바일은 유형/프로젝트/작업일자를 같은 보조 줄에 표시합니다.

## 오른쪽 타임라인
- 오늘 목록은 유지하며 타임라인 아이콘 하나로 보조 패널을 엽니다. 기본 닫힘, 본문 폭·좌표 변경 없음.
- 충분한 오른쪽 여백에는320px 패널, 부족하면 겹침,580px 이하 전체 화면. 시간 미정 오늘 선택 항목은 상단에 표시하고 시간 배치로 연결합니다.
