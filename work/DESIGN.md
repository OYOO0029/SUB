# 업무 화면 현재 UX 규격

이 문서는 현재 규격의 단일 기준입니다. 최신 사용자 요청을 우선하고, 변경된 절을 교체합니다. 과거 규격은 docs/history에만 보관합니다. 작업 절차는 WORKING_RULES.md를 따릅니다.

## 목적과 기본 구조 — 사용자 확정
- 지금 할 일이 주 화면입니다. 기존 오늘 할 일 / 프로젝트 / 캘린더 메뉴와 다크 스타일을 유지합니다.
- 새 카드·설명·설정의 증설을 줄이고 기존 목록·공통 선택 메뉴·날짜 편집기·옆 상세를 사용합니다.
- 기본 흐름은 제목 등록 → 필요한 정보 지정 → 작업 → 완료 → 기록 조회입니다.
- 제목 클릭은 어디서나 같은 상세, 체크박스는 완료, ⋯는 추가 작업 메뉴입니다. 다중 선택은 명시적 선택 모드의 별도 버튼입니다.
- 삭제·선택 날짜 목록 제외는 ⋯ 안에 텍스트로 표시합니다. 달력 아이콘을 이동/제외에 쓰지 않습니다. 집중·스톱워치 진입은 기본 목록과 상세에서 제거하고 기존 측정 데이터는 보존합니다.

## 날짜와 오늘 화면
- 이전 날짜 / 선택 날짜 / 다음 날짜 / 오늘 복귀. 선택 날짜를 목록과 시간표가 공유합니다.
- 오늘 목록 → 기한 지난 일 → 예정된 할 일 → 날짜 없는 할 일 순서입니다. 완료 포함을 선택하면 완료 목록을 별도 표시합니다. 비어 있는 보조 표를 반복하지 않습니다.
- 선택 날짜 포함(dayPlans), 작업일자(workPeriod), 작업 시간(blocks), 마감일(deadline 및 due 호환값), 완료 시각(completedAt), 업무 묶음 기간은 독립입니다.
- 목록 추가·제외는 선택 날짜의 포함 여부만 변경하며 원래 기간·마감·프로젝트를 변경하지 않습니다. 다음 날 자동 이월하지 않습니다. 어제 미완료 중 필요한 항목을 개별 추가합니다.
- 작업일자가 있다는 이유로 마감으로 표시하지 않습니다. 기한 초과는 실제 마감일로 판정하며 날짜 없는 항목은 초과가 아닙니다.
- 과거 목록은 저장된 계획·작업·완료 기록을 보여주고 당시 완료 체크는 읽기 전용입니다. 제목으로 여는 상세는 현재 항목을 편집합니다. 과거 기록 없는 실적은 만들지 않습니다.
- 직접 정렬은 오늘·전체 프로젝트·직접 정렬 상태에서만 사용합니다. 기존 todayOrder를 보존합니다.

## 목록과 추가
- 완료 / 할 일 / 유형 / 프로젝트 / 작업일자 / ⋯. 특정 프로젝트에서는 프로젝트 열을 숨깁니다. 기한 지난 목록만 지연일수를 추가합니다.
- 제목 한 줄, 긴 제목은 말줄임·전체 툴팁·상세에서 확인합니다. 업무명·태그·설명은 제목에 덧붙이지 않습니다.
- 열 헤더는 텍스트입니다. 완료 포함과 정렬은 공통 도구에서 조작합니다. 행 버튼 공간을 확보해 노출 시 이동이 없도록 합니다.
- 마지막의 낮은 강조 '+ 할 일 추가'는 항상 표시합니다. 제목만으로 Enter 연속 등록하며 프로젝트 미선택도 허용합니다.
- 프로젝트/업무 묶음/선택 날짜에서 추가하면 해당 맥락만 반영합니다. 새 업무 묶음을 자동 생성하지 않습니다. 프로젝트별·날짜별 초안을 분리합니다.
- 한글 조합 중 Enter와 연타 중복을 막습니다. 실패 시 입력과 생성 ID를 유지하고 재시도에서 중복 생성하지 않습니다.
- 모바일은 체크·제목·⋯ 첫 줄, 유형·프로젝트·날짜 보조 줄, 빈 날짜는 숨김입니다. 페이지 전체의 가로 넘침을 막고 필요한 표만 내부 스크롤합니다.

## 프로젝트와 업무 묶음
- 기본 프로젝트 목록: 현황 / 프로젝트명 / 기간 / 남은 할 일 수. 프로젝트 추가를 텍스트로 노출합니다. 이름만 필수이고 등록 후 해당 프로젝트 할 일로 이어집니다.
- 진행/완료/전체 전환과 완료 프로젝트 재진입을 유지합니다. 프로젝트 완료가 할 일을 자동 완료하지 않습니다.
- 상세 이름·현황·기간 바로 아래에 보기와 할 일을 배치합니다. 사업비·관련 인원·설명·관련 링크는 프로젝트 정보에 모읍니다.
- 할 일 / 일정(WBS) / 업무별 보기 / 기록. 기본은 평평한 할 일입니다. WBS는 프로젝트→업무 묶음까지만 표시합니다.
- 업무 묶음은 선택 사항이며 할 일 상세에서 바로 선택/해제합니다. 묶음 안의 추가는 자동 연결, 일괄 연결은 별도 선택 모드입니다.
- 묶기·해제는 동일 할 일 ID를 유지합니다. 묶음 삭제는 할 일을 삭제하지 않고 프로젝트 소속을 보존합니다. 업무 기간과 할 일 날짜는 서로 변경하지 않습니다.

## 상세와 저장
- 공통 옆 패널: 제목·완료 → 유형·프로젝트·업무 묶음·작업일자·작업 시간·마감일 → 메모 → 작업 기록 → 리마인드.
- 날짜와 시간을 가까이 둡니다. 비어 있는 하위 체크리스트는 숨기고 기존 내용은 보존합니다. 불필요한 추가 설정 토글은 쓰지 않습니다.
- 상세 열기·닫기·확대가 목록 폭과 스크롤·필터를 변경하지 않습니다. 모바일은 한 화면 상세로 제공합니다.
- 자동 저장은 한글 조합 종료 이후 처리합니다. 편집 중 / 기기에 저장됨·동기화 대기 / 서버 동기화 완료 / 실패를 구분합니다. 서버 확인 없이 완료 표시하지 않습니다.
- 실패 시 입력·초안을 유지하고 재시도 제공합니다. 실패·유효성 오류 중 닫기/항목 전환은 보호합니다. 완료·목록 이동·삭제에는 결과와 실행 취소를 제공합니다.

## 시간표와 캘린더
- 진입 이름은 '시간표'. 목록의 선택 날짜·프로젝트 필터를 공유합니다. 넓은 화면은 320px 보조 영역, 좁으면 별도 화면으로 표시합니다. 상세를 열 때 시간표를 잠시 숨기고 닫으면 스크롤을 복원합니다.
- 기본 09–18시 중심, 다른 시간도 조회·편집 가능합니다. 오늘에만 현재 시각 선·지금 이동을 제공합니다.
- 제목은 공통 상세, 시간은 시간 편집. 빈 시간은 기존 할 일 선택/제목만 새 등록 후 시간 지정입니다.
- 시간 길이에 비례하며 짧은 일정은 압축 표현, 겹침은 별도 열. 완료 항목은 낮은 강조로 남깁니다. 예정 시간을 실제 수행으로 계산하지 않습니다.
- 캘린더 날짜는 해당 날짜 목록, 항목은 공통 상세. 주/월 경계·작업 기간·실제 마감을 별도로 표현합니다.

## 기록·검색·복구
- 날짜별 계획과 예정 시간, 사용자가 작성하는 날짜+한 줄 작업 기록, 실제 완료/완료 취소를 별도 이벤트로 저장합니다.
- 변경 시 당시 제목·프로젝트 맥락을 기록합니다. 이후 이름·소속·날짜 변경이 과거 기록을 덮어쓰지 않습니다. 기록은 할 일 상세와 해당 프로젝트에서 기간으로 조회합니다. 전체 검색에서도 기록 범위를 제공합니다.
- 기존 tasks/works/projects ID와 연결·메모·첨부·체크리스트·휴지통·타이머 데이터는 보존합니다. 새 이력 필드는 선택 사항이며 일괄 파괴적 마이그레이션을 하지 않습니다.
- 기존 todaySelected는 최초 관찰 날짜만 식별하고 저장되지 않은 과거 실적을 추정하지 않습니다.
- 백업/복원은 기존 설정을 사용하며 이력도 동일 저장 경로로 포함합니다. 이미지 이동은 '기존 메모 첨부 보관'으로 설명하고 원본 첨부를 유지합니다.
- 날짜 형식은 공통 설정에만 둡니다. 퇴근 시간 표시 기본 ON 및 기존 유형·리마인드·검색·완료 필터·정렬을 유지합니다.

실제 사용자 데이터에 테스트를 하지 않습니다. 분리 fixture에서 정상·실패·IME·연속 입력·삭제복원·재접속·PC/모바일을 검사하고 tests/ux-review.md에 통과/실패/미검증을 구분합니다. 기능 테스트 통과를 시각 검수 완료로 대신하지 않습니다.
