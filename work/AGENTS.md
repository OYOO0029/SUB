# 업무 화면 작업 지침

이 디렉터리의 기능·UI·문서를 수정할 때 [WORKING_RULES.md](WORKING_RULES.md)와 [DESIGN.md](DESIGN.md)를 먼저 읽고 적용합니다.

- WORKING_RULES.md는 정보 집중, 쉬운 추가·편집, 정렬·여백, 검증의 기준입니다. DESIGN.md는 화면별 현재 동작과 치수의 기준입니다.
- 최신 사용자 요청을 우선합니다. 기준이 바뀌면 해당 문서를 함께 갱신하고, README의 과거 변경 이력을 최신 규칙으로 되살리지 않습니다.
- 화면을 수정하기 전에 사용자가 확인하거나 처리할 일과 기본 표시할 정보를 정합니다. 검색·필터·접기·상세로 보고 싶은 정보에 집중할 수 있는지 확인합니다.
- 같은 역할의 정렬·간격·스타일을 재사용합니다. 기본 빈 입력란, 중복 설명, 연속 팝업, 먼 위치의 추가 버튼을 새로 만들지 않습니다.
- 변경 범위에 맞춰 긴 내용·빈 상태·좁은 화면·키보드 접근을 확인합니다. 날짜·정렬·저장 동작을 바꿀 때는 관련 검사도 수행합니다. 문서만 바꿨다면 링크·내용·diff를 확인합니다.
- 기존 사용자 데이터와 작업 중인 입력을 보존합니다. UI 검증용 데이터는 분리된 로컬 환경을 사용합니다.
