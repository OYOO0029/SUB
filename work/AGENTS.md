# 업무 화면 작업 지침

수정 전에 [WORKING_RULES.md](WORKING_RULES.md)와 [DESIGN.md](DESIGN.md)를 읽습니다.

- DESIGN.md는 현재 UX 규격의 유일한 기준입니다. docs/history는 변경 이력이며 현재 규칙을 덮어쓰지 않습니다.
- 사용자 최신 요청을 우선하되 변경된 규칙은 해당 절을 교체합니다. ‘최신 기준’ 절을 계속 추가하지 않습니다.
- 같은 역할의 메뉴·아이콘·행 추가·날짜는 공통 컴포넌트를 재사용합니다. 스타일 수정은 기존 소유 규칙에서 수행하고 후속 중복 덮어쓰기를 추가하지 않습니다.
- 확정 요구와 에이전트의 구현값을 구분합니다. 사용자에게 동일한 정렬·크기 기준을 반복해서 묻지 않습니다.
- 공통 변경은 오늘·프로젝트·캘린더와 상세 화면을 함께 검수합니다. 기능 테스트와 시각 검수, 배포 확인을 각각 보고합니다.
- 기존 데이터·관계·계정 저장을 보존하고 로컬 가상 데이터로 검수합니다.
