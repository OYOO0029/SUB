# SUB

- 개인 일정: `/schedule.html`
- 업무: `/work/` — 동일한 계정으로 저장·동기화하며 상단에서 개인/업무를 전환합니다.
- 기존 개인 일정과 가계부 데이터는 각각의 저장 영역을 유지합니다.

업무 미리보기의 백업 이전과 동기화 정책은 [업무 안내](work/README.md)를 참고하세요. 사용자 백업 JSON은 이 공개 저장소에 올리지 않습니다.

검증: `npm ci` 후 `npm test`. 브라우저 검증은 `node tests/schedule-preview.mjs`로 가상 계정과 메모리 서버를 사용합니다.
